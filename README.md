# AI Coding Skills

这是一个面向 AI 编程协作的技能集合，当前包含文档处理、压测脚本生成和测试用例生成三类能力。

## 技能列表

- `docx-cn`：Word 文档（`.docx`）创建、读取、编辑与分析
- `jmeter-generator`：根据接口文档生成 JMeter `.jmx` 压测脚本
- `testcase-generator`：根据需求文档生成 Excel 测试用例

## 使用方式

1. 根据任务选择对应技能目录。
2. 阅读对应目录下的 `SKILL.md`。
3. 按技能说明准备输入文件和环境依赖。
4. 执行生成、编辑或导出流程。

## 目录结构

- `jmeter-generator/`
- `testcase-generator/`
